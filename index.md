## 💡 What is zrpc?
zrpc is a modern framework that helps you create Remote Procedure Calls (RPC) in Elixir. With its simple Domain Specific Language (DSL), middleware support, and structured routing, you can define your API once. This makes it easy to automatically generate TypeScript clients and OpenAPI specifications. It's designed for efficiency, helping you focus more on building your application rather than the underlying technology.

## 🚀 Getting Started
To get started with zrpc, follow these easy steps to set it up on your computer. You do not need to have programming skills for this process.

1. **Verify System Requirements**
   - Operating System: Windows, macOS, or Linux.
   - Elixir version: Ensure you have Elixir installed on your machine.
   - Sufficient disk space to install the application.

2. **Install Elixir**
   - *Windows Users*: Download and install from the official [Elixir website](https://elixir-lang.org/install.html).
   - *macOS Users*: Use Homebrew. Open your terminal and type:
     ```bash
     brew install elixir
     ```
   - *Linux Users*: Use your package manager. For Ubuntu, use:
     ```bash
     sudo apt-get install elixir
     ```

3. **Download zrpc**
